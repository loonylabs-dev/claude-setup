# Keeping every CLAUDE.md healthy

- A CLAUDE.md is not documentation — it is the set of rules that change behaviour,
  loaded in full every session. Keep it distilled; push detail into referenced docs
  or skills rather than inlining it. Size counts in **characters, not lines** — a
  line budget just buys denser lines and reports no growth while the file grows.
- An entry is the generic law — failure mode → rule, in one sentence — not the story
  of how it was found. When something recurs, sharpen the existing entry instead of
  stacking an Nth-instance paragraph beside it; prune stale ones. A rule already
  decided against is not a fresh proposal — its reason is written down.
